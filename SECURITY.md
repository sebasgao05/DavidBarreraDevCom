# Politica de Seguridad / Security Policy

---

## Espanol

### Como reportar una vulnerabilidad

Si descubres una vulnerabilidad de seguridad en este proyecto, por favor reportala de forma responsable enviando un correo electronico a:

**sebasgao05@icloud.com**

**No** abras un issue publico para reportar vulnerabilidades de seguridad.

### Que cuenta como vulnerabilidad

- Inyeccion de codigo (XSS, SQL injection, etc.)
- Exposicion de datos sensibles
- Falsificacion de solicitudes (CSRF)
- Acceso no autorizado a recursos
- Vulnerabilidades en dependencias que afecten directamente al sitio
- Cualquier problema que comprometa la integridad, confidencialidad o disponibilidad del sitio

### Tiempos de respuesta esperados

- **Confirmacion de recepcion:** dentro de 48 horas
- **Evaluacion inicial:** dentro de 7 dias
- **Resolucion o plan de accion:** dentro de 30 dias (dependiendo de la severidad)

### Alcance

Esta politica aplica al sitio [david-barrera.com](https://david-barrera.com) y al codigo fuente de este repositorio.

## English

### How to report a vulnerability

If you discover a security vulnerability in this project, please report it responsibly by sending an email to:

**sebasgao05@icloud.com**

**Do not** open a public issue to report security vulnerabilities.

### What counts as a vulnerability

- Code injection (XSS, SQL injection, etc.)
- Sensitive data exposure
- Cross-site request forgery (CSRF)
- Unauthorized access to resources
- Vulnerabilities in dependencies that directly affect the site
- Any issue that compromises the integrity, confidentiality, or availability of the site

### Expected response times

- **Acknowledgment of receipt:** within 48 hours
- **Initial assessment:** within 7 days
- **Resolution or action plan:** within 30 days (depending on severity)

### Scope

This policy applies to [david-barrera.com](https://david-barrera.com) and the source code of this repository.
