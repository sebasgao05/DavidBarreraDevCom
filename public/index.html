David Barrera - Data Engineer & Ingeniero de Sistemas

Data Engineer en Blend360 | Bogota, Colombia

David Barrera es un Ingeniero de Sistemas graduado de la Universidad EAN, actualmente trabajando como Data Engineer en Blend360. Se especializa en el diseno e implementacion de pipelines de datos escalables utilizando Python, SQL, AWS Glue, Amazon Redshift, Apache Spark y arquitecturas serverless en la nube de AWS.

Con experiencia previa como Desarrollador de Aplicaciones en IBM, David Barrera combina conocimientos solidos en desarrollo de software con expertise en ingenieria de datos. Su perfil incluye manejo de tecnologias como Java, Spring Boot, React, TypeScript, Node.js, Docker y servicios de AWS como Lambda, S3, EC2, DynamoDB, API Gateway, CloudWatch y ECS.

Ademas de su experiencia profesional, David Barrera es AWS Community Builder en la categoria DevTools y fue Student Builder Group Leader (SBGL) del AWS Cloud Club en la Universidad EAN, donde lideraba workshops y eventos tecnicos sobre arquitecturas cloud y mejores practicas en desarrollo.

Su portafolio incluye proyectos como sistemas de calculo de tarifas con APIs serverless, soluciones IoT en la nube, generadores de hojas de vida y este mismo sitio web, desarrollado con React, TypeScript y Tailwind CSS, desplegado en AWS S3 con CloudFront y CI/CD automatizado mediante GitHub Actions.
