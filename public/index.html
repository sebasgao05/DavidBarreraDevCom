David Barrera - Ingeniero de Software & Desarrollador AWS Cloud

Software Engineer en Blend360 | Bogotá, Colombia

David Barrera es Ingeniero de Software y AWS Cloud Developer en Bogotá, Colombia. Ingeniero de Sistemas graduado de la Universidad EAN, actualmente forma parte del programa All Star en Blend360, donde desarrolla soluciones backend y cloud con Java, Python y JavaScript.

Como AWS Cloud Developer, David domina servicios como AWS Lambda, Amazon S3, DynamoDB, AppSync, Cognito y Amplify. Su enfoque combina desarrollo de software robusto con arquitecturas cloud modernas para entregar soluciones de alto rendimiento. Cuenta con la certificación AWS Certified Cloud Practitioner y es AWS Community Builder en la categoría DevTools.

Su experiencia profesional incluye su rol como Practicante Desarrollador de Aplicaciones en IBM, donde realizó migración a la nube, modernización de apps legacy hacia AWS y automatización de procesos DevOps, reduciendo un 30% las actividades manuales. También domina TypeScript, React, Spring Boot, GraphQL, Docker y herramientas de CI/CD.

Como líder comunitario, David fue Student Builder Group Leader del AWS Cloud Club en la Universidad EAN, donde organizó 24+ eventos técnicos con 400+ asistentes presenciales y 60 virtuales. Colaboró con 7+ grupos en Colombia para promover tecnologías cloud. Actualmente contribuye a la comunidad mediante contenido técnico y mentoría.

Su portafolio incluye proyectos como una aplicación full stack serverless de finanzas personales con AWS Amplify Gen 2, sistemas de cálculo de tarifas con APIs serverless, soluciones IoT en la nube y generadores de hojas de vida. Este sitio web está desarrollado con React, TypeScript y Tailwind CSS, desplegado en AWS S3 con CloudFront y CI/CD automatizado. Puede descargar su CV para más detalles sobre su trayectoria.

David Barrera cuenta con certificaciones como AWS Certified Cloud Practitioner, IBM Generative & Agentic AI Foundation y AWS Cloud Club Captain Gold Level. Su formación académica en la Universidad EAN incluyó desarrollo de software, arquitectura de sistemas y tecnologías emergentes. Habla español nativo e inglés intermedio (B2). Está comprometido con el aprendizaje continuo y busca constantemente nuevas formas de construir soluciones de software escalables.
