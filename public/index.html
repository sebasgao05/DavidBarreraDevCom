David Barrera - Data Engineer & AWS Cloud Specialist

Data Engineer en Blend360 | Bogotá, Colombia

David Barrera es Data Engineer y AWS Cloud Specialist en Bogotá, Colombia. Ingeniero de Sistemas graduado de la Universidad EAN, actualmente trabaja como Data Engineer en Blend360, donde se especializa en el diseño e implementación de pipelines de datos escalables utilizando Python, SQL, AWS Glue, Amazon Redshift y Apache Spark.

Como AWS Cloud Specialist, David domina servicios como AWS Lambda, Amazon S3, DynamoDB, ECS y CloudFormation. Su enfoque combina ingeniería de datos robusta con arquitecturas cloud modernas para entregar soluciones de alto rendimiento. Cuenta con la certificación AWS Certified Cloud Practitioner y es AWS Community Builder en la categoría DevTools.

Su experiencia profesional incluye roles como Desarrollador de Aplicaciones en IBM, donde participó en proyectos de transformación digital con Java, Spring Boot y React. También domina TypeScript, Node.js, Docker y herramientas de CI/CD para automatización de despliegues.

Como líder comunitario, David fue Student Builder Group Leader del AWS Cloud Club en la Universidad EAN, donde organizaba workshops y eventos técnicos sobre arquitecturas cloud y mejores prácticas en AWS. Actualmente contribuye a la comunidad mediante contenido técnico y mentoría.

Su portafolio incluye proyectos como sistemas de cálculo de tarifas con APIs serverless, soluciones IoT en la nube y generadores de hojas de vida inteligentes. Este sitio web está desarrollado con React, TypeScript y Tailwind CSS, desplegado en AWS S3 con CloudFront y CI/CD automatizado. Puede descargar su CV para más detalles sobre su trayectoria.

David Barrera cuenta con certificaciones como AWS Certified Cloud Practitioner, IBM Agile Explorer y AWS Cloud Club Captain Gold Level. Su formación académica en la Universidad EAN incluyó desarrollo de software, arquitectura de sistemas y tecnologías emergentes. Habla español nativo e inglés intermedio (B2). Está comprometido con el aprendizaje continuo y busca constantemente nuevas formas de optimizar procesos de datos a escala empresarial.
